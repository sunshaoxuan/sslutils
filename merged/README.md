# Merged Output Directory (merged/)

## Purpose
This directory contains the **final, ready-to-deploy** certificate files generated by the Toolkit.
Files in this directory are the result of merging server certificates with their intermediate chains.

## Rules
1. **Source**: Files here are automatically generated by `Merge-CertificateChain.ps1`.
2. **Content**:
   - `*.cer`: Full Chain Certificate (Server + Intermediate). Ready for Apache/Nginx.
   - `*.pfx`: PKCS#12 Archive (Certificate + Key). Ready for IIS/Tomcat.
   - `*.key`: Unencrypted Private Key (if copied/converted by options).
3. **Git Policy**:
   - **Do NOT commit** any certificate or key files.
   - This directory is for production deployment artifacts only.

## Deployment
- **Apache/Nginx**: Use the `.cer` (Fullchain) and the corresponding `.key` from `new/` (or here if synced).
- **IIS/Tomcat**: Use the `.pfx` file.
